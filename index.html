일정과 SDK에 관한 핵심 사실은 다음과 같다.

  3. 공모전에서 소개하는 SDK와 공개 문서상 현재 사용 가능한 SDK 범위가 다르다. Vehicle State와 NaviHelper는 신청 없이 사용 가능하지만, FusedLocation·TextToSpeech·SpeechToText·Vehicle Control은 "준비 중"으로 신청조차 불가하다.3

1. 공모전 개요

1.1 기본 정보

현대자동차그룹의 차량용 인포테인먼트 플랫폼 Pleos Connect에서 사용할 앱을 발굴하는 공모전이다. 차량 상태, 이동 과정, 운전자와 동승자의 상황을 활용해 새로운 고객 경험을 제공하는 서비스가 대상이며, 주제 제한은 없다.45

공식 개요가 예시로 든 고객 니즈 영역은 모빌리티·라이프 편의, 인카 엔터테인먼트, 스마트 드라이빙·안전, 패밀리·동승자 케어이며, 이 밖의 주제도 자유롭게 출품할 수 있다.8

1.2 상금과 경쟁 구조

본상 총상금은 5,100만 원이다. 숏폼 챌린지 어워드 50만 원은 별도다.9

상격 팀당 상금 선정 팀
대상 1,000만 원 대학생 1팀, 일반 1팀
최우수상 600만 원 대학생 1팀, 일반 1팀
우수상 400만 원 대학생 2팀, 일반 2팀
아이디어 특별상 150만 원 부문 통합 2팀
숏폼 챌린지 어워드 50만 원 별도 1팀

일반 부문에는 대상·최우수상·우수상 합계 네 자리가 있고, 부문 통합 특별상 두 자리가 따로 있다.

전체 지원팀 수는 공개되지 않았으므로 1차 경쟁률은 알 수 없다. 다만 이후 단계의 비율은 공고로 확정되어 있다.

  • 1차 합격 20팀 중 10팀이 최종 선정된다. PT 단계의 통과율은 50%다.
  • 본상과 특별상 자리를 합치면 4 + 4 + 2 = 10으로 최종 선정 10팀과 같다. 상격 배분이 공고대로 유지되면 최종 선정은 곧 수상이고, PT 이후 남는 문제는 순위다.
  • 단, 공고는 "응모작 수와 심사 기준에 따라 시상 작품 수가 조정되거나 수상작이 없을 수 있다"고 유보한다.10

1.3 수상팀 지원

수상팀에게 Pleos App Market 탑재 준비를 지원한다. 다만 별도 검증·심사와 차종·지역 조건이 적용되며, 입점이나 배포는 보장되지 않는다.11

개발 시작 전에 Pleos Playground 가입 → Workspace > My Project에서 프로젝트 생성 → SDK 사용 상태 확인 순서를 거친다. TextToSpeech·SpeechToText처럼 서버 연결이 필요한 SDK는 프로젝트의 클라이언트 ID와 시크릿을 쓴다.23

4.2 공개 문서상 SDK 사용 가능 상태

프로젝트 생성 및 SDK 사용 신청 문서와 API 호환성 문서는 다음과 같이 안내한다.2425

SDK 또는 기능 공개 문서상 상태 차종별 호환성
Vehicle State 별도 신청 없이 사용 가능 차종별 상이, checkXXXCapabilities로 확인
NaviHelper 별도 신청 없이 사용 가능 내비 탑재 차량에서만 완전 호환
Vehicle Control 준비 중, 신청 불가 —
FusedLocation 준비 중, 신청 불가 차종별 상이, isSupported로 확인
TextToSpeech 준비 중, 신청 불가 공개되면 전 차종 호환
SpeechToText 준비 중, 신청 불가 공개되면 전 차종 호환

공모전 개발 안내는 위 SDK를 모두 소개하고, 음성 메모 앱(SpeechToText) 같은 예시도 든다.26

NaviHelper는 목적지 설정·확인·취소, 경로 옵션 변경과 재탐색, 경유지 추가·조회·삭제, 경로 탐색·주행 상태 이벤트 수신, 내비게이션 정보 조회와 화면 요청 기능을 제공한다. 요청은 Pleos Connect 내비게이션 앱으로 전달되며, 전달되는 이벤트는 내비게이션 앱의 구현과 현재 상태에 따라 달라질 수 있다. NaviHelper는 내비게이션이 탑재된 차량에서만 완전 호환된다.2728

확인 범위: 위 상태는 공개 문서를 읽은 결과다. 참가 계정에서 실제 SDK 호출이 성공하는지 검증한 결과는 아니며, 공모전 전용 권한 제공 여부도 공개 안내만으로 확정하지 못했다.

4.3 차종별 데이터·권한 확인

SDK 사용이 가능하더라도 모든 차량 속성을 사용할 수 있다는 뜻은 아니다. 차종과 속성별로 지원 여부나 접근성이 달라질 수 있다. 공식 문서는 Vehicle SDK의 checkXXXCapabilities와 AAOS의 CarPropertyManager 등을 통해 실제 지원 여부를 확인하도록 안내하고, 모델명으로 분기하지 말라고 명시한다. SDK에 없는 특수 속성이 필요하면 구현 전에 기술지원팀 검토를 요청해야 한다.29

앱 심사에서는 필요한 퍼미션을 선언하고, 사전 협의·승인된 범위에서 사용해야 한다는 안내도 있다.30

4.4 주행 중 UI 제한

Pleos 앱은 플랫폼이 전달하는 CarUxRestrictions에 따라 기능을 제한해야 한다. CarUxRestrictionsManager에 리스너를 등록해 onUxRestrictionsChanged()로 상태를 받고, ActiveRestrictions 플래그(예: UX_RESTRICTIONS_NO_VIDEO)를 기능별로 적용한다. Distraction Optimization(DO)을 선언한 앱도 제한 상태가 활성화되면 직접 제한을 적용해야 하며, 지역별 제한 규칙은 플랫폼이 알려 준다.31

4.5 Virtual Console 시뮬레이션 범위

Pleos Connect Virtual Console의 Emulation Controls는 도메인별로 가상 상태를 바꿔 앱 동작을 확인하게 해 준다.32 문서에 나온 주요 항목은 다음과 같다.

도메인 조작 가능한 상태(일부)
Motion 기어(P/R/N/D), 브레이크 페달, 주행거리, 조향각
Convenience 도어 개폐·잠금, 트렁크, 창문, 좌석 점유, 실내등, 와이퍼, 방향지시등
Energy 배터리 SOC, 배터리 에너지, 잔여 주행거리, 충전 스위치, 충전 포트, 충전 목표치
Climate 공조 전원, 에어컨, 목표 온도, 팬 속도

5. 플랫폼 기본 기능

5.1 공식 소개에 포함된 기능

현대자동차그룹의 2026년 4월 30일 공식 Pleos Connect 소개에는 다음 기능이 포함되어 있다.33

  • Gleo AI를 통한 목적지와 주변 식당 검색
  • 자연어 차량 제어와 차량 매뉴얼 정보 제공
  • 뉴스·날씨 등 웹검색
  • 내비게이션과 미디어 서비스
  • YouTube·Spotify 등 외부 서비스 연동

이는 해당 공식 발표의 소개 내용이며, 모든 차종·지역의 현재 설치 앱 목록을 의미하지는 않는다. Pleos 개발 문서에도 "Gleo 인터페이스 구현" 가이드가 있어, 기본 AI 비서와의 연동 지점이 존재한다.34

6. 접수양식과 제출물 요건

6.1 공식 접수양식 구성

공식 접수양식이 곧 기획서다. DOCX 양식은 「01 참가신청서」, 「02 앱 프로젝트 소개/심사 자료」, 「03 개인정보 수집·이용 동의서」, 「04 대표자·팀원별 동의 확인 및 서명」으로 구성되며, 작품 소개 자료에는 분량 제한이 없다.35

「02 앱 프로젝트 소개/심사 자료」의 항목은 다음과 같다.36

  1. 앱 한 줄 소개
  2. 기획 배경
  3. 앱 주요 기능 및 차량 특화 요소
  4. 주요 사용 시나리오
  5. 개발 계획(Pleos Connect 구현 범위, SDK/API 사용계획)
  6. 기대효과 및 발전 가능성(타깃 고객 분석, 예상 MAU, Retention Rate, 향후 서비스 확대 계획 등)
  7. 참고자료(선택, 가산점 부여)
  8. 숏폼 링크(선택, 가산점 없음)

심사 자료는 익명으로 작성해야 한다. 접수양식은 02 작품 소개에 대표자·구성원의 성명·연락처·이메일·소속을 넣지 말라고 안내하고, 공유 링크와 첨부자료에도 개인정보·계정정보·개발자 실명이 노출되지 않도록 확인하라고 한다.37

6.2 단계별 개발 산출물 요건

6.4 숏폼 챌린지

숏폼은 본상과 별도인 참여형 행사다. 본상 총상금 5,100만 원과 별개로 1팀에 50만 원을 시상하며, 본상 가산점은 없다.4344

참여 조건은 30초~1분 세로 영상을 개인 또는 팀 계정의 Instagram 릴스나 YouTube Shorts에 올리고, 필수 해시태그 #HMG차량용앱개발공모전을 포함해 해시태그 2~3개를 다는 것이다.45

7. 권리와 수상 후 의무

출품작의 지식재산권은 참가자에게 있으며, 수상작에는 다음 조건이 함께 안내되어 있다.46

항목 공고 내용
창작물 요건 표절 작품과 이미 발표된 타 공모전 수상작은 심사 제외

기존 상용 서비스 확장판의 허용 범위는 공개 안내만으로 확정하기 어려웠다.

오픈소스를 사용하면 라이선스를 준수하고 출처를 밝혀야 한다. 이용약관은 제출 기술자료를 심사·운영 목적 외에 무단 사용·제공하지 않으며 비밀유지를 위한 보안조치를 한다고 안내한다.47 개인정보 처리는 수탁사(주식회사 스터닝)를 통해 진행된다.48

상금은 대표자에게 일괄 지급되며, 주최 측은 팀 내 분쟁을 중재하지 않는다.49

8. 설명회와 운영국에 확인할 질문

답변에 따라 아이디어나 개발 일정이 달라질 수 있는 질문을 우선 정리했다. 이 문서 작성 과정에서 운영국에 문의를 보내지는 않았다.

  1. 참가자에게 실제 개방되는 SDK는 무엇인가? 준비 중으로 표시된 위치·음성·차량 제어 기능에 공모전 전용 권한 또는 공개 일정이 있는가? 없다면 AAOS 표준 음성·위치 API로 대체해도 되는가?

  2. PT에서 사용하는 에뮬레이터와 SDK 버전은 무엇인가? 개인 노트북 사용, 네트워크 제공, 외부 백엔드 연결 조건은 어떻게 되는가?

  3. 2차 결과물 제출 마감과 발표·시연 시간은 언제 확정되는가?

  4. Private GitHub 심사용 계정과 심사자료 익명성 기준은 무엇인가? 계정명과 커밋 작성자 표시를 어떻게 처리해야 하는가?

  5. 기존 서비스의 차량용 확장판을 출품할 수 있는가? 기존 코드·데이터·아이디어의 활용 범위와 타 공모전 수상 이력 관련 판단 기준은 무엇인가?

  6. 2027년 2월 필수 참석 날짜·인원과 전시 지원 범위는 무엇인가?

  7. 학생과 일반인의 혼합팀 또는 복수 출품은 어떻게 처리되는가? 해당하는 경우 부문 결정과 출품 가능 범위를 확인한다.

  8. IP 우선협상권의 기준이 되는 결과 발표일은 언제인가? 12월 18일 최종 선정 발표인지, 2027년 2월 순위 발표인지 확인한다. 사업화 계획이 있다면 구체적인 적용 시점과 협의 절차도 확인한다.
